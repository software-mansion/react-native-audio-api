# AudioListener

The `AudioListener` interface represents the position and orientation of the person listening to the audio scene.
It is used for 3D spatialization: all `PannerNode` objects spatialize sound in relation to the context's listener.

`AudioListener` is **not** an [`AudioNode`](./audio-node.mdx) — it has no inputs, outputs, or `connect()`/`disconnect()` methods. It only exposes nine [`AudioParam`](./audio-param.mdx) properties.

Every [`BaseAudioContext`](./base-audio-context.mdx) exposes a single listener through its read-only `listener` property — you never construct one yourself.

- The `positionX`, `positionY` and `positionZ` parameters represent the location of the listener in 3D Cartesian coordinate space.
- The `forwardX`, `forwardY` and `forwardZ` parameters represent a direction vector in 3D space — which direction the listener's "nose" is pointing.
- The `upX`, `upY` and `upZ` parameters represent the direction the top of the listener's head is pointing.

The `forward` and `up` vectors are expected to be linearly independent.

## Example

```tsx
import { AudioContext } from 'react-native-audio-api';

const ctx = new AudioContext();
const listener = ctx.listener;

// Move the listener 3 meters along the x axis.
listener.positionX.value = 3;

// Or automate the movement over time.
listener.positionX.linearRampToValueAtTime(10, ctx.currentTime + 2);
```

## Properties

All properties are [`AudioParam`](./audio-param.mdx)s with `minValue`/`maxValue` spanning the full single-precision float range (approximately ±3.4028235e38), a-rate automation.

| Name | Type | Default value | Description | |
| :----: | :----: | :----: | :-------- | :-: |
| `positionX` | [`AudioParam`](./audio-param.mdx) | `0` | x-coordinate of the listener's position. | <ReadOnly /> |
| `positionY` | [`AudioParam`](./audio-param.mdx) | `0` | y-coordinate of the listener's position. | <ReadOnly /> |
| `positionZ` | [`AudioParam`](./audio-param.mdx) | `0` | z-coordinate of the listener's position. | <ReadOnly /> |
| `forwardX` | [`AudioParam`](./audio-param.mdx) | `0` | x-component of the listener's forward direction. | <ReadOnly /> |
| `forwardY` | [`AudioParam`](./audio-param.mdx) | `0` | y-component of the listener's forward direction. | <ReadOnly /> |
| `forwardZ` | [`AudioParam`](./audio-param.mdx) | `-1` | z-component of the listener's forward direction. | <ReadOnly /> |
| `upX` | [`AudioParam`](./audio-param.mdx) | `0` | x-component of the listener's up direction. | <ReadOnly /> |
| `upY` | [`AudioParam`](./audio-param.mdx) | `1` | y-component of the listener's up direction. | <ReadOnly /> |
| `upZ` | [`AudioParam`](./audio-param.mdx) | `0` | z-component of the listener's up direction. | <ReadOnly /> |

## Methods

Prefer setting the `AudioParam` properties above. These helpers exist for Web Audio API compatibility.

| Method | Description |
| :---- | :-------- |
| `setPosition(x, y, z)` | Sets `positionX/Y/Z.value` (deprecated in the spec). |
| `setOrientation(forwardX, forwardY, forwardZ, upX, upY, upZ)` | Sets `forwardX/Y/Z.value` and `upX/Y/Z.value` (deprecated in the spec). Unlike [`PannerNode.setOrientation`](../effects/panner-node.mdx#methods), this takes six arguments (forward + up). |

## Remarks

- Used by [`PannerNode`](../effects/panner-node.mdx) for 3D spatialization relative to the listener.
