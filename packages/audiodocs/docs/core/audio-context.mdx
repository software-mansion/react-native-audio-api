# AudioContext

The `AudioContext` interface inherits from [`BaseAudioContext`](/docs/core/base-audio-context).
It is responsible for supervising and managing audio-processing graph.

## Constructor

```tsx
constructor(options?: AudioContextOptions)
```

### `AudioContextOptions`

| Parameter | Type | Default | |
| :---: | :---: | :----: | :---- |
| `sampleRate` <Optional /> | `number` | - | The preferred sample rate for the context. |

#### Errors

| Error type | Description |
| :---: | :---- |
| `NotSupportedError` | `sampleRate` is outside the supported range [`3000`, `768000`]. |

## Properties

`AudioContext` does not define any additional properties.
Inherits all properties from [`BaseAudioContext`](/docs/core/base-audio-context#properties).


## Methods

Inherits all methods from [`BaseAudioContext`](/docs/core/base-audio-context#methods).

### `createMediaElementSource`

Creates [`MediaElementAudioSourceNode`](/docs/sources/media-element-audio-source-node), routing media playback into the audio graph.

| Parameter | Type | Description |
| :---: | :---: | :---- |
| `mediaElement` | `HTMLMediaElement` (web) \| [`AudioTagHandle`](/docs/sources/audio-tag#ref-handle-audiotaghandle-methods) (native) | Media element to route into the graph. On native, wait for [`onLoad`](/docs/sources/audio-tag#props-audioprops) on `<Audio>` before calling. |

#### Returns [`MediaElementAudioSourceNode`](/docs/sources/media-element-audio-source-node).

### `close`

Closes the audio context, releasing any system audio resources that it uses.

#### Returns `Promise<undefined>`.

### `suspend`

Suspends time progression in the audio context.
It is useful when your application will not use audio for a while.

#### Returns `Promise<void>`.

### `resume`

Resumes a previously suspended audio context.

#### Returns `Promise<void>`.
