# DelayNode

The `DelayNode` interface represents latency in an audio signal by a given amount of time. It is an [`AudioNode`](../core/audio-node.mdx) that applies time shift to incoming signal f.e.
if `delayTime` value is `0.5`, it means that audio will be played after `0.5` seconds.

:::info
Delay is a node with tail-time, which means that it continues to output non-silent audio with zero input for the duration of `delayTime`.
:::

## Constructor

```tsx
constructor(context: BaseAudioContext, options?: DelayOptions)
```

### `DelayOptions`

Inherits all properties from [`AudioNodeOptions`](../core/audio-node.mdx#audionodeoptions).

| Parameter | Type | Default | |
| :---: | :---: | :----: | :---- |
| `maxDelayTime` <Optional /> | `number` | `1.0` | Maximum amount of time, in seconds, to buffer delayed values. |
| `delayTime` <Optional /> | `number` | `0.0` | Initial value for [`delayTime`](./delay-node.mdx#properties). |

You can also create a `DelayNode` via the [`BaseAudioContext.createDelay(maxDelayTime?: number)`](../core/base-audio-context.mdx#createdelay) factory method, which uses default values when called without arguments.

## Remarks

#### `maxDelayTime`
- Default value is `1.0`.
- Nominal range is `0.0` - `180.0`.

#### `delayTime`
- Default value is `0.0`.
- Nominal range is `0.0` - `maxDelayTime`.
